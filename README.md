# EC2 State Monitoring with CloudWatch Alarm

## Project Overview
This project deploys an AWS EC2 instance using Terraform
and monitors CPU utilization using Amazon CloudWatch.

## Technologies Used
- AWS EC2
- Amazon CloudWatch
- Terraform
- AWS IAM

## Features
- Automated EC2 provisioning
- CloudWatch CPU monitoring
- CPU utilization alarm at 70%
- Infrastructure as Code

## Deployment Commands

terraform init
terraform validate
terraform plan
terraform apply

## Cleanup

terraform destroy
